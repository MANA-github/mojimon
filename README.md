# もじモン 文字きれい度チェッカー

**書いた文字を1文字入力**して、その手書き写真をアップロードすると、きれいさを100点満点で採点するサイトです。
サーバー不要で、`index.html` をブラウザで開くだけで動きます。画像はブラウザ内だけで処理します。

## しくみ

1. 写真から文字（いちばん大きいもの＋近くの濁点など）を切り出す
2. 入力された文字を**パソコンのフォントで描いてお手本**を作る
3. 両方を同じ大きさにそろえて**細線化（骨組みだけに）**し、骨組み同士のずれを測る
4. ひらがな・カタカナ・小1の漢字など約250字とも比べ、**お手本より近い別の字があれば「見間違い」**と判定
   （例：「わ」と入力したのに「れ」の方が近い → 総合点は59点まで）

## 採点項目

| 項目 | 内容 | 初期の重み |
|---|---|---|
| 字形の正確さ | お手本の骨組みとの平均距離 | 40% |
| 読みやすさ | お手本との距離 ÷ いちばん近い別の字との距離 | 30% |
| バランス | 重心の位置と縦横比がお手本どおりか | 15% |
| 線の安定感 | 線の太さのばらつき | 15% |

## カスタマイズ（js/config.js）

### 採点を厳しく／甘くしたい
`metrics` の各項目の `good` と `bad` を変えます。
- ずれの値が `good` 以下なら **100点**、`bad` 以上なら **`minScore` 点**（初期値20）
- 両方を**小さく**すると厳しく、**大きく**すると甘くなります

### 見間違いの扱いを変えたい
- `misreadCap`：別の字に読めたときの総合点の上限（100 にすると上限なし）
- `match.candidates`：見間違いを調べる文字の一覧。よく練習する漢字を足すと、その字との見間違いも判定できます
- `match.sameShape`：「カ」と「力」のように形で区別できない文字のグループ。ここに入れた組は見間違いにしません

### お手本のフォントを変えたい
`match.fonts` に CSS のフォント指定を並べます（インストールされていないものは自動で省かれます）。
書いた字はいちばん近いフォントと比べます。教科書体（Windows の「UD デジタル 教科書体」）が手書きに近くおすすめです。

### ランクやメッセージを変えたい
`ranks`（上から順に `min` 点以上で判定）、各項目の `tip`、画面の文言は `text`。
`text` の `{target}` `{rival}` `{cap}` は、入力した字・見間違えた字・上限点に置き換わります。

### 色を変えたい
`css/style.css` 冒頭の `:root`（`--good` 緑 / `--mid` 黄 / `--bad` 赤 / `--accent` / `--accent2`）。
何点から緑・黄にするかは `config.js` の `colorThresholds`。

### 採点項目を追加したい
1. `js/metrics.js` の `METRICS` に関数を追加（0〜100を返す。判定できないときは `null`）
2. `js/config.js` の `metrics` に同じ `key` で名前・重み・`good`/`bad`・`tip` を追加

関数が受け取る `r` には、お手本との距離 `r.target.d`、いちばん近い別の字 `r.rival`、
書いた字とお手本の特徴 `r.target.uv` / `r.target.tv`（`grid` 64×64のマス, `pts` 骨組み, `cx,cy` 重心, `aspect` 縦横比）などが入っています。

### 文字がうまく切り出せないとき（`detect`）
- 薄い文字が拾えない → `inkMinDiff` を小さく、`inkRatio` を大きく（例: 12, 0.88）
- ゴミ・汚れを拾う → `minAreaRatio` を大きく
- 濁点や離れた部品が別扱いになる → `joinDistance` を大きく

## 限界
- お手本はフォントなので、書道的な美しさ（とめ・はね・はらいの筆づかい）までは評価できません
- 見間違い判定は `match.candidates` に入っている文字との比較だけです
